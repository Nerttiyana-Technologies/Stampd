# Stampd.Timestamp.Rfc3161

Generic configurable RFC 3161 timestamp authority provider for Stampd. Works with FreeTSA, DigiCert, GlobalSign, Sectigo, internal AD CS / OpenSSL TSAs — anything that speaks RFC 3161 over HTTP.

Part of [Stampd](https://github.com/isureshsubramanian/Stampd) — open-source PDF signing for .NET. Apache 2.0.

## Install

```
dotnet add package Stampd.Timestamp.Rfc3161
```

See the [Stampd repository](https://github.com/isureshsubramanian/Stampd) for the full architecture, getting-started guide, and the rest of the Stampd packages.
