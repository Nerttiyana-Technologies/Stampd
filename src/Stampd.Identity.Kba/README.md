# Stampd.Identity.Kba

Knowledge-Based Authentication IIdentityVerificationProvider. Pluggable IKbaProvider abstraction for LexisNexis, Experian, Equifax, and similar commercial KBA backends; ships a MockKbaProvider for dev.

Part of [Stampd](https://github.com/isureshsubramanian/Stampd) — open-source PDF signing for .NET. Apache 2.0.

## Install

```
dotnet add package Stampd.Identity.Kba
```

See the [Stampd repository](https://github.com/isureshsubramanian/Stampd) for the full architecture, getting-started guide, and the rest of the Stampd packages.
