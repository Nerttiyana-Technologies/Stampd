# Stampd.Storage.AzureBlob

Azure Blob Storage-backed IDocumentStorageProvider. Stores signed documents in a configured container. Auth via DefaultAzureCredential (Managed Identity / workload identity / Azure CLI / env).

Part of [Stampd](https://github.com/isureshsubramanian/Stampd) — open-source PDF signing for .NET. Apache 2.0.

## Install

```
dotnet add package Stampd.Storage.AzureBlob
```

See the [Stampd repository](https://github.com/isureshsubramanian/Stampd) for the full architecture, getting-started guide, and the rest of the Stampd packages.
