# Stampd.Crypto.LocalCertificate

Local X.509 certificate ICryptographicSealingProvider for Stampd. Suitable for self-hosted production where the signing certificate is stored on disk or in the OS certificate store.

Part of [Stampd](https://github.com/isureshsubramanian/Stampd) — open-source PDF signing for .NET. Apache 2.0.

## Install

```
dotnet add package Stampd.Crypto.LocalCertificate
```

See the [Stampd repository](https://github.com/isureshsubramanian/Stampd) for the full architecture, getting-started guide, and the rest of the Stampd packages.
